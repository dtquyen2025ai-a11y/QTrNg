# Chùa Tâm An – Web đi chùa online

Web tĩnh (HTML/CSS/JS thuần, không cần server, không thư viện ngoài) để "lên chùa" mỗi ngày:

- **Gõ mõ / Niệm Phật**: chạm hoặc nhấn Space, đếm chuỗi 108 hạt, tự gõ, thỉnh chuông (âm thanh tổng hợp bằng WebAudio).
- **Thắp hương**: 1/3/5 nén, hương cháy theo thời gian thật (15 phút).
- **Xin xăm**: mỗi ngày 1 quẻ, 14 quẻ với thơ lục bát tự soạn.
- **Thả hoa đăng**: viết lời nguyện, đèn trôi trên hồ.
- **Sổ công đức**: tổng công đức, 8 bậc danh hiệu, chuỗi ngày liên tục, biểu đồ 7 ngày.
- Cảnh chùa đổi ngày/đêm theo giờ thật; hỗ trợ dark mode; tối ưu điện thoại.

Dữ liệu lưu trong `localStorage` của trình duyệt.

## Chạy
Mở `index.html` trực tiếp, hoặc bật GitHub Pages (Settings → Pages → branch này, thư mục `/`).
